# Third-party notices

Generated file — do not edit by hand. It lists the third-party crates a shipped binary
(`bifrost`: core, agent, GUI and lightweight tray roles) contains, with their terms.
The project itself is MIT: see [`../LICENSE`](../LICENSE).

Regenerate from the repository root, after `cargo fetch`:

```sh
cargo install cargo-about --locked     # or take the release binary for your target
cargo about generate --workspace --fail -o licenses/THIRD_PARTY_NOTICES.md licenses/notices.hbs
```

Dev-dependencies are excluded (`about.toml`: `ignore-dev-dependencies = true`) because they are
not part of a shipped artifact. The same policy is enforced as a gate by
`cargo deny check licenses` (see [`../deny.toml`](../deny.toml)); the human-readable audit is
`docs/08-reuse-and-licenses.md`.

The GUI disables egui's default fonts and embeds the OFL-licensed families listed below.
These licence texts must travel with the binary.

The fonts bundled with `lws-gui` (Geist, Geist Mono, Silkscreen; `apps/lws-gui/assets/fonts/`) are
not crates and are therefore not produced by cargo-about: the last section is static text kept in
`licenses/notices.hbs`. `cargo deny` / `about.toml` do not see it either — update the section by
hand whenever a font file is added, replaced or removed.
